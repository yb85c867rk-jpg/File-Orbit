B. Create Map -> file Save:
- Title-only and populated creation now invokes the existing Save picker before candidate installation:
  - pickCreationDestination() uses documentAdapter.pickSave with safeDocumentFilename(title) e.g. "Solo Root.map".
  - invoked synchronously by the Create/Replace click path before installation awaits.
- Picker cancellation returns keepDraft; Create Map dialog retains title/preview/selection and outgoing map/destination.
- After candidate installation and immediate recovery baseline, creation calls the existing saveDocument(target handle/forceDownload) path:
  - write and close must succeed before activeDocument adoption;
  - tree/metadata/attachment bytes preserved;
  - no write to outgoing handle;
  - confirmed save sets destination, clean revision, retires recovery baseline;
  - write/close failure leaves live new map unsaved, activeDocument inactive, Retry available through Save.
- Fallback (writable APIs unavailable): install live map, request .map download, keep dirty/recovery, report unconfirmed handoff.
- Duplicate submission blocked; one picker write and one install for the successful attempt.

C. Editor Save reuse:
- Confirmed destination handle is reused by Add Folder/Add Data form Save and toolbar Save; no picker per edit.
- Recovery baseline retirement/creation ordering covered by create-baseline test.
