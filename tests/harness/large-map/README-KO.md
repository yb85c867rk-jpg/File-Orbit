# FileOrbit 전체 지도 + 활성 하위 트리 — 사용자 테스트

## 실행

```powershell
cd C:\Users\openw\Documents\Projects\FileOrbit-git
python -m http.server 8164 --bind 127.0.0.1 --directory .
```

Chrome/Edge: `http://127.0.0.1:8164/tests/harness/large-map/index.html`

## 1. 300 이하: 전체 지도

1. `20개 카테고리 · depth 3–7` + `free` + `Load`.
2. 20개 카테고리 이름이 읽히는지 확인.
3. 폴더/파일 전체 구조가 지도에 남아 있는지 확인.
4. 카테고리 하나를 클릭 → 선택한 하위 트리가 중앙에 밝게 펼쳐지고 나머지는 어둡게 유지되는지 확인.
5. 배경의 다른 카테고리를 클릭해 전환.
6. `뒤로`, `루트로`로 카메라 복귀.

## 2. 300 초과: 개요 + 활성 트리

1. `wide` + `paid-test` + `301` + `Load`.
2. 파일은 숨고 폴더 개요만 보이는지 확인.
3. `와이드-그룹-1` 클릭 → 파일 17개가 밝게 펼쳐지고 배경 폴더는 어둡게 남는지 확인.
4. 다른 배경 카테고리를 클릭해 전환.
5. `1,000` paid-test로 같은 동작 확인.

## 3. 카메라

- 휠: 포인터 기준 확대/축소.
- `+`, `−`, `Fit`.
- 배경 드래그 이동.
- 폴더 클릭 후 자동 확대/축소.
- 자동 이동 중 휠/드래그 → 점프 없이 중단.
- `뒤로`/브레드크럼/`루트로` 카메라 복원.

## 4. 파일/검색/미리보기

- 파일 클릭은 선택만; 폴더 확장 아님.
- TXT/MD/PDF/PNG 미리보기.
- `보고서.pdf` 검색 → 경로로 20개 구분.
- 검색 결과 페이지 이전/다음, 숨은 가지로 이동.
- `검색 지우기`로 입력/결과/강조 제거.
- 다른 폴더로 이동하면 이전 미리보기 제거.

## 5. 정리

- A 검색/미리보기 → B Load: 이전 상태가 남지 않아야 함.
- 로딩 중 Unload: 지도가 되살아나지 않아야 함.
- Unmount 후 모든 버튼 비활성.
