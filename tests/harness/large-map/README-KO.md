## 1. 실제 20개 카테고리

1. 샘플에서 `20개 카테고리 · depth 3–7`을 선택하고 **Load**.
2. 루트에 20개 카테고리가 보이는지 확인.
3. `01_기획` 폴더를 그래프에서 직접 클릭 → 하위 폴더/파일 표시.
4. `뒤로`로 루트 복귀, `루트로`도 확인.
5. `05_마케팅`으로 이동해 가장 깊은 7단계까지 폴더를 그래프에서 클릭.
6. 각 단계에서 브레드크럼이 맞는지, 이전 위치로 `뒤로`가 되는지 확인.

## 2. 카메라

- 마우스 휠: 포인터 위치 기준 확대/축소.
- `+`, `−`, `Fit` 버튼 확인.
- 배경 드래그로 이동.
- 폴더 클릭 시 자동으로 새 장면에 맞게 확대/축소되는지 확인.
- 자동 이동 중 휠/드래그를 하면 애니메이션이 취소되고 점프하지 않아야 함.

## 3. 파일과 미리보기

1. 폴더 안의 파일을 클릭 — 폴더처럼 확장되지 않고 선택만 되어야 함.
2. `미리보기`로 TXT/MD/PDF/PNG 확인.
3. PDF 2페이지, PNG 이미지 표시 확인.
4. 미리보기 후 다른 폴더로 이동해 잔상이 없는지 확인.

## 4. 검색

1. `보고서.pdf` 검색 — 같은 이름 20개를 경로로 구분.
2. 결과 클릭 시 숨은 하위 폴더로 이동하고 대상이 선택되는지 확인.
3. `검색 지우기`로 강조/결과 제거.
4. 깊은 1,000-node 스트레스 샘플에서 `이전 결과`/`다음 결과` 페이지 이동 확인.

## 5. 정리

- 다른 샘플을 Load해 이전 검색/미리보기/선택이 사라지는지 확인.
- Unload 후 +/−/Fit/뒤로/미리보기 버튼이 비활성인지 확인.
